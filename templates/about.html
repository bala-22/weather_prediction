About This Project

Weather Prediction System

Project Objective

This project aims to build an intelligent weather forecasting system specifically designed for Tiruchirappalli (Trichy). The system leverages machine learning algorithms to analyze historical weather patterns and predict future weather conditions, with a focus on rainfall prediction which is critical for agriculture, water management, and daily life in the region.

Machine Learning Methodology

1. Data Collection

Historical weather data is collected for Tiruchirappalli covering temperature, humidity, rainfall, pressure, wind speed, and cloud cover. Data sources include OpenWeatherMap API and preprocessed sample datasets based on real climate patterns for the region.

2. Data Cleaning

Raw data undergoes cleaning to remove duplicates, validate ranges appropriate for Tiruchirappalli's climate, and handle outliers. Missing values are addressed using time-series interpolation methods.

3. Feature Engineering

Additional features are derived from raw data including temporal features (day of year, month, season), lag features (previous day values), and rolling averages (3-day and 7-day windows).

4. Model Training

Multiple classification models are trained and compared: Random Forest, Logistic Regression, and XGBoost (if available). The best performing model is selected and saved for predictions.

5. Model Evaluation

The model is evaluated on a held-out test set using accuracy, precision, recall, F1-score, and confusion matrix analysis. All metrics are computed from actual test predictions — no fabricated accuracy values.

6. Prediction

The trained model is used to predict rain/no-rain for each sub-area in Tiruchirappalli. Predictions are compared against actual historical observations for evaluation.

Dataset

The dataset contains weather observations for Tiruchirappalli covering the past 6 months. Each record includes:

  • Temperature (average, minimum, maximum) in degrees Celsius
  • Humidity (%)
  • Rainfall (mm)
  • Atmospheric pressure (hPa)
  • Wind speed (m/s)
  • Cloud cover (%)
  • Weather condition description

Note: When the OpenWeatherMap API is configured, the system fetches real data. Otherwise, it uses a sample dataset generated from Tiruchirappalli's actual climate statistics — clearly labeled as sample data.

Evaluation Metrics

Metric Formula Description
Accuracy (TP + TN) / (TP + TN + FP + FN) Overall correctness of predictions
Precision TP / (TP + FP) Of predicted rain days, how many actually had rain
Recall TP / (TP + FN) Of actual rain days, how many were correctly predicted
F1-Score 2 * (Precision * Recall) / (Precision + Recall) Harmonic mean of precision and recall

Rain Classification Threshold: A day is classified as "Rain" if rainfall ≥ 0.1 mm. This threshold is configurable in the application settings.
